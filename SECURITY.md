# Security

This integration signs in to your Baby Tracker account and keeps a copy of your
babies' records, so security problems matter here. If you find one (for example
a way to read the photos or records without logging in to Home Assistant, or
credentials ending up in logs or diagnostics), please report it privately
through [GitHub's private vulnerability reporting](https://github.com/isaiahnicolai/baby-tracker-home-assistant/security/advisories/new)
rather than in a public issue.

Only the latest release gets fixes.
